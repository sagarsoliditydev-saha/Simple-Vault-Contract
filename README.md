# Simple-Vault-Contract
A secure Simple Vault smart contract for depositing and withdrawing funds securely.# Simple Vault Smart Contract

A decentralized vault smart contract built with Solidity that allows users to securely deposit and withdraw funds.

## Features
- **Deposit Function:** Users can deposit ETH into the vault, and their balance is tracked securely using mappings.
- **Withdraw Function:** Allows users to withdraw their deposited funds safely after balance verification.
- **Mapping Storage:** Efficiently tracks individual user balances using Ethereum addresses.
